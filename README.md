Weather CLI
Консольное приложение на Python для получения текущей погоды в Москве с использованием OpenWeatherMap API, с использованием Docker-контейнера и GitLab CI/CD.

Что реализовано:
    - Код в weather.py, который делает запрос к api погоды, обрабатывает ошибки ответа сервера и выводит данные в консоль.
    - В .env лежит секретный токен от OpenWeatherMap API, в .gitignore прописано скрыть этот файл.
    - Контейнеризация - Создан Докер образ в файле Dockerfile.
    - Автоматизация - настроен пайплайн GitLab CI/CD (этап build), который автоматически собирает Docker-образ и отправляет его на Docker Hub.

Как запускать проект:
    - Если нужно установите и запустите Docker Desktop.
    - Создайте в корне проекта файл .env и добавьте туда ваш API-ключ так: WEATHER_API_KEY=ключ.
    - Откройте терминал в папке проекта и выполните команду для сборки образа: docker build -t weather-local .
    - Запустите собранный контейнер, передав ему файл с переменными окружения: docker run --rm --env-file .env weather-local

Как проверять результат:
    - После запуска команды docker run в консоль должны успешно выводиться актуальные данные о погоде
    - При отправке кода в GitLab автоматически запускается пайплайн со сборкой
    - После прохождения пайплайна образ автоматически публикуется на Docker Hub.
